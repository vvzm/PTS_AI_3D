# 大尺寸非接触三维测量技术方案

## 项目介绍

本项目聚焦于 **大尺寸（4m × 4m × 2m）高精度（优于 0.1mm）非接触三维测量** 技术方案的调研与实现。面向飞机机身段、风电叶片、列车车厢、大型模具等工业场景，解决高光金属/漆面表面在无贴标约束下的快速三维测量难题。

### 核心需求

| 指标 | 要求 |
|------|------|
| 测量范围 | 4m（宽）× 4m（高）× 2m（长） |
| 测量精度 | 优于 0.1mm（相对精度 1:20,000） |
| 测量时间 | ≤ 5 分钟 |
| 表面要求 | 不允许贴标，无污染/损伤，支持高光金属及漆面 |
| 测量方式 | 非接触无损 |

### 核心挑战

1. **大尺寸 vs 高精度** — 2m 量程与 0.1mm 精度形成 1:20,000 动态范围
2. **高光表面测量** — 金属光泽/漆面强镜面反射导致常规传感器信号丢失
3. **无贴标约束** — 无法使用编码标记点进行多视角拼接
4. **5 分钟时限** — 需在 300 秒内完成大面积密集扫描

详细技术调研见 [大尺寸非接触三维测量技术方案调研报告](./docs/调研报告/大尺寸非接触三维测量技术方案调研报告.docx)。

### 推荐方案

综合技术成熟度、精度保障和成本因素，推荐 **方案八-A（激光跟踪仪 + 手持激光扫描仪）**：

- **全局层：** Leica AT960 激光跟踪仪（AIFM 精度 ≤ 0.5µm/m），2m 量程单站覆盖无需拼接
- **局部层：** Leica T-Scan 5 手持激光扫描仪（210,000 点/秒采集速率）
- **系统精度：** 预计 < 0.08mm，满足 0.1mm 要求
- **成本：** 约 150~400 万元

## 技术方案总览

本报告共调研 8 大类技术方案：

| # | 方案名称 | 核心原理 |
|---|---------|---------|
| 1 | 相干激光雷达 | FMCW / 光频域啁啾干涉测量 |
| 2 | 激光跟踪仪 + 非接触扫描探头 | 激光干涉测距 + 6DoF 跟踪 |
| 3 | 光学跟踪式三维扫描 | 内置相机阵列 SLAM 自定位 |
| 4 | 自适应条纹投影结构光 | 正弦条纹投影 + 相位解算 |
| 5 | 摄影测量 + 结构光混合 | 散斑投影 DIC + 局部高密度扫描 |
| 6 | 相位测量偏折术 (PMD) | 镜面反射条纹相位偏移分析 |
| 7 | 激光频率梳 | 飞秒脉冲 / 双梳干涉绝对测距 |
| 8 | 多技术融合综合方案（推荐） | 全局-局部双层级测量架构 |
